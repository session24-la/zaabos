# ZaabOS Round 14H.2 — Navigation Hierarchy

Primary navigation order is now:
1. POS
2. Menu
3. Order History
4. Kitchen
5. More

This keeps the highest-frequency front-of-house work first and keeps secondary
management modules inside More. Desktop/iPad and mobile bottom navigation use
the same order so staff do not have to relearn navigation between devices.

No database, payment, order, shift, refund, reporting, or pricing logic changed.
