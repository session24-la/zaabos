# ZaabOS Round 14H — POS Workspace Redesign

UI/UX-only restructuring based on the latest Railway-passed Round 14G baseline.

- POS is now the primary workspace: table board first, active table/order context only.
- Order history moved to its own History tab; the POS home no longer grows with historical order cards.
- Kitchen is a first-class navigation destination.
- Desktop/iPad navigation is compact: POS / History / Kitchen / Menu / More.
- Secondary management modules live under More instead of extending a horizontal scrolling tab strip.
- Mobile uses five stable bottom navigation targets; secondary modules open from a clean More sheet.
- Branch selector moved into the header as a compact control.
- QR All Tables moved into Tables & QR where it belongs.
- Wider desktop workspace and cleaner table cards.
- No database/schema/order/payment/shift logic changes.
